## The same notebook on pandas 3.0.6 (not the pinned version)

An earlier run in a separate venv with pandas 3.0.6, NumPy 2.4.6 and Matplotlib 3.11.2 also finished without errors (20 s) but prints **83** instead of **126** for the number of unpaid users who attempted a quiz. Cause, checked directly: `pd.read_csv('user_quiz_attempt_data.csv')` has 0 missing values in `started_at` on pandas 1.5.3 and 7,871 on pandas 3.0.6, because newer pandas reads the text `None` as missing, and the notebook's `merge(...).dropna()` then drops those rows. This is why `requirements.txt` pins pandas 1.5.3.
